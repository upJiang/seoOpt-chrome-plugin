# Chrome Web Store 审核说明

版本：0.8.0

## 扩展用途

SEO优化用于分析用户主动选择的网站，显示页面 SEO、技术交付、国际 SEO、分析追踪和 SEM 证据，并提供本地生成的优化建议和网页定位。

扩展不自动修改网页、服务器、CDN、分析标签、广告账户、预算或出价。

## 基础审核步骤

1. 安装 `seo-opt-chrome-plugin-0.8.0-chrome.zip`。
2. 打开任意普通 HTTP 或 HTTPS 页面，例如 `https://example.com/`。
3. 点击扩展图标，Chrome 侧边栏会打开并自动扫描当前页面。
4. 在“概览”查看页面 SEO 基础分、正常项、扣分项、页面信息和页面数据。
5. 在“问题”查看直接证据和网页定位。
6. 在“优化建议”展开任意方案，查看代码、变量解释、验证和回滚。
7. 在“海外站优化”查看海外市场建设判断和五项能力。

基础扫描只使用用户操作后取得的 activeTab 权限，不要求登录、创建账号、填写项目或连接外部平台。

## 可选网站权限测试

“站点审计”、跨域关联版本检查和跨域追踪需要持续读取特定来源。扩展只在用户主动使用对应功能时请求具体网站权限。

用户拒绝权限后，扩展仍可显示当前页面基础报告，并把无法完成的跨域检查写入检测边界。扩展不会反复弹出权限请求。

## 追踪测试

普通扫描不会持续监听页面事件。

进入“海外站优化 > 追踪”，用户主动点击开始后，扩展才临时观察分析事件、请求和 SPA 路由。停止测试、达到 10 分钟、页面卸载或权限失效后，扩展恢复包装的方法。

扩展只记录事件名、平台、相对时间、目标 ID 和关键字段是否存在，不保存请求正文、表单值、Cookie、完整 dataLayer/uetq 或真实业务 ID。

## CSV 数据核对

搜索表现、GA4、广告和业务结果 CSV 由用户主动选择。解析在本地 Web Worker 中完成，原始文件不会长期保存。姓名、邮箱、电话和地址等身份字段禁止映射。

## 可选 AI 功能

AI 功能默认关闭，不是基础审核所必需。

用户可以自行配置兼容 OpenAI `/chat/completions` 的 HTTPS 服务地址、模型和 API Key。只有用户主动发送问题时，扩展才向该服务发送脱敏诊断上下文。扩展不包含开发者运营的 AI 代理地址，也不会把 Key 或报告自动发送给开发者。

## 远程代码与第三方脚本

扩展不下载或执行远程代码。所有执行代码均包含在扩展包中。

页面中已有的 GA4、GTM、Google Ads、Bing UET、Clarity 或百度统计脚本只作为检查对象。外部 AI 服务只返回文本响应，响应不会作为 JavaScript 执行。

## 数据保存

扫描报告和设置默认保存在 Chrome 本地扩展存储或 IndexedDB。扩展不使用 chrome.storage.sync，不包含开发者遥测、广告 SDK 或跟踪像素。用户可以在扩展内删除项目数据、导入数据、追踪历史、AI Key、AI 对话或全部本地数据。

## 无法由扩展确认的结果

扩展不会把以下内容写成已经确认的结果：

- Google 或 Bing 已经收录页面；
- 页面已经获得关键词排名；
- 分析或广告平台后台已经接收事件；
- 线索、订单或收入已经真实产生；
- 证书到期时间、证书链或 TLS 等级。

这些内容会显示为检测边界，需要 Search Console、平台后台、服务器日志或业务数据确认。
