# Chrome Web Store 权限用途说明

版本：0.8.0

## 单一用途

分析用户主动选择的网站搜索增长信号，并在本地提供可解释的 SEO、国际 SEO、追踪链路与 SEM 诊断、优化建议和网页元素定位。

## activeTab

仅在用户点击扩展图标、重新扫描或使用网页定位时，临时访问当前活动标签页。该权限用于读取当前页面的标题、元数据、正文结构、链接、媒体、结构化数据和可测性能信号。

扩展不会使用 activeTab 持续记录用户访问的网站，也不会在用户没有主动操作时批量读取标签页内容。

## tabs

用于识别当前活动标签页的 URL、标签页 ID 和页面导航状态，使侧边栏能够加载与当前页面匹配的报告，并在页面地址变化后清除旧结果或重新扫描。

扩展不会使用 tabs 建立、出售或上传浏览历史。

## scripting

用于按需注入以下本地脚本：

- 当前页面 SEO 采集器；
- 网页问题定位标注层；
- 用户主动开始追踪测试时的临时观察器。

所有注入脚本均随扩展包发布。扩展不下载或执行远程 JavaScript，也不使用 eval 执行远程代码。

## storage

用于在 Chrome 本地保存：

- 当前会话扫描报告和页面状态；
- 网站记录、站点审计和扫描基线；
- 用户主动导入后规范化的搜索、分析、广告和业务字段；
- 脱敏追踪测试、日志聚合和海外核对结果；
- 用户设置的 AI 服务地址、模型、API Key 和对话。

扩展不使用 chrome.storage.sync。用户可以删除单项数据、当前网站数据、AI Key、AI 对话或全部本地数据。

## sidePanel

用于在 Chrome 侧边栏展示扫描状态、问题、优化建议、海外站诊断、AI 解读和 SEM 结果。这是扩展的主要界面。

## optional_host_permissions

清单声明 `https://*/*` 和 `http://*/*` 为可选主机权限，但不会在安装时授予，也不会在普通页面扫描时自动申请全部网站权限。

扩展只在用户主动运行以下功能时，按具体来源申请所需权限：

- 持续扫描当前网站；
- 对当前来源运行站点审计；
- 检查跨域语言页或移动版关联地址；
- 继续跨域转化追踪测试；
- 访问用户配置的 AI 服务地址。

用户拒绝权限后，扩展会把对应结果显示为未授权或检测边界，不会在每次扫描时反复弹出请求。用户可以随时在 Chrome 扩展设置中撤销权限。

## 未申请的高风险权限

扩展不申请以下权限：

- debugger；
- webRequest；
- declarativeNetRequest；
- cookies；
- history；
- downloads；
- 常驻必选 `<all_urls>` 主机权限。

## 外部网络请求

页面探测、robots.txt、Sitemap、站点审计和同源资源响应头检查使用匿名请求，不发送 Cookie、Authorization 或表单数据。

可选 AI 功能默认关闭。只有用户填写服务地址、模型和 API Key，并主动发送问题后，扩展才会向用户选择的兼容 OpenAI 服务发送脱敏诊断上下文。远程 AI 地址必须使用 HTTPS，本机 localhost 和 127.0.0.1 除外。

## 远程代码声明

扩展不加载、下载或执行远程代码。外部 AI 服务仅返回文本响应，不返回可执行代码供扩展运行。网页中已有的脚本只作为被检查对象，扩展不会复制后执行。
