# Chrome Web Store 重新提交说明

提交版本：`0.8.0`

## 针对上次拒绝的修改

上次审核返回的违规参考 ID 是 `Yellow Argon`，原因是商品说明中包含过多技术关键词。

本次重新提交已经重写商品说明：

- 只保留一个清晰的核心用途：检查用户主动选择的网页，并提供可执行的修改建议；
- 删除连续罗列的技术名词、平台名称和指标名称；
- 删除可能被理解为排名、流量或收入承诺的表达；
- 将权限、数据处理和详细技术边界放入独立的权限说明与隐私政策，不再用商品描述堆叠关键词；
- 商品说明改为说明用户如何使用扩展、能够看到什么结果，以及哪些结果需要外部平台确认。

## 商品页实际内容

扩展会在 Chrome 侧边栏检查当前网页，展示页面情况、直接证据和修改方案。建议会说明问题位置、修改位置、代码含义、验证方式和恢复方式。

用户可以主动检查一批页面，也可以在需要时进行海外页面和数据记录核对。相关操作不会自动运行，不会连接广告账户，不会修改网站或服务器。

插件不保证搜索收录、关键词排名、流量、转化或收入。商品说明、权限说明、审核测试说明和隐私政策中的功能边界保持一致。

## 审核测试

1. 打开任意普通 HTTP 或 HTTPS 网页。
2. 点击扩展图标，查看侧边栏自动生成的页面报告。
3. 打开“问题”查看直接证据。
4. 打开“优化建议”查看修改说明和验证方法。
5. 需要测试批量页面或数据记录时，再主动进入对应功能并授权。

基础页面检查不需要登录、注册或连接第三方账户。
