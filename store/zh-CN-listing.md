# Chrome 应用商店中文文案

## 名称

SEO优化 - 页面审计与网页标注

## 简短说明

本地检查页面、站点、国际 SEO 与 Google/Bing 追踪，并给出含代码解释的 SEO/SEM 优化方案。

## 详细说明

SEO优化面向站长、SEO/SEM 从业者、开发者和创业网站运营者。点击扩展后，它会直接在 Chrome 侧边栏中扫描当前页面，不要求先创建项目或填写市场、关键词和广告信息。六个视图依次为概览、问题、优化建议、海外站优化、AI 深度解读和 SEM。

检查范围包括匿名真实 GET 状态、HTTPS 与正式主机、HSTS、混合资源、压缩和缓存响应头、Google/Bing/百度 robots 规则、Canonical、原始与渲染内容差异、Title、Description、H1、内部链接、图片、JSON-LD、Sitemap、CSS/JavaScript 加载候选、nofollow，以及 LCP、CLS、FCP、TTFB 等本次访问性能。证书到期、证书链和 TLS 等级会明确显示为不可测。

“问题”默认只显示失败和警告，简要列出结论、发现位置、直接证据、影响范围和严重程度。点击“网页定位”可在原页面显示独立标注层，标注不会修改页面元素样式或造成布局位移；点击“查看完整优化建议”会跳转到对应方案，并保留问题筛选和滚动位置。

“网站优化方案”是插件的核心结果。它按已确认阻断、高影响、高置信度增长、风险候选和外部数据缺口排序，并可按页面访问与收录、标题内容与搜索意图、内链媒体与结构化数据、性能与资源加载、国际 SEO、数据追踪和 SEM 筛选。每项方案说明：问题为什么出现、为什么值得优化、证据是什么、应该采用什么策略、修改哪个位置、代码怎样写、每一部分是什么意思、替换哪些变量、怎样验证和怎样回滚。

代码会根据可识别的 WordPress、Shopify、Next.js、Nuxt/Vue、React SPA、静态 HTML、Nginx、Apache 和常见 CDN 提供实现。证据不足时，扩展先展示最终 HTML、响应或事件应该达到的目标，再提供常见技术栈方案，不武断断言框架。Canonical、hreflang 等示例会使用当前域名和路径；Schema 只使用页面已确认事实，不虚构价格、评分、库存或作者。

每项方案严格区分“修改后的直接结果”“可能带来的搜索或业务效果”和“不能保证的结果”。普通网页的索引目标默认保持未知，避免把有意不收录的页面误判为阻断；页面类型综合 URL、面包屑、Title、H1、按钮、表单、正文、分页和 Schema 判断，不确定时只显示候选。

“页面 SEO 基础分”只反映当前页面可测信号，不代表实际收录或关键词排名。索引目标未知或测量覆盖不足时，扩展会降低结论强度。实际排名、外链、真实用户 Core Web Vitals 和转化数据需要外部平台验证，不会被包装成插件结论。

建立搜索项目后，用户可以主动运行“站点审计”。它默认快速检查 20 个代表页面，需要确认影响范围时再扩大到 50 或 100 页；检查状态码、跳转、索引指令、Canonical、近似重复、页面模板、内链、Sitemap、hreflang、HTML 压缩/缓存和站内 nofollow。检查遵守 robots.txt，孤立页、重复内容和内链机会会明确标注样本限制；它不是完整全站爬虫，不能证明全站收录、排名、外链或转化。

扩展支持导入 Google Search Console、Bing、百度搜索表现 CSV，以及 Google、Bing、百度广告表现、创意和业务结果 CSV。CSV 与可选服务器日志均由 Web Worker 在本地解析，不保存原始文件；服务器日志只保存去除 IP、Referer 和原始 User-Agent 后的聚合结果。

“海外站优化”包含概况、问题、优化建议和追踪。概况按搜索访问、语言与地区、数据统计、广告与业务展示自动检查结果；问题只保留直接异常证据，优化建议提供完整策略、代码解释、验证和回滚，追踪页集中放置标签证据、现场测试与三方数据核对。单语言网站不会因没有 hreflang 被误报；缺少 GA4/GTM 只在需要衡量 Google/Bing 海外流量时作为条件性机会，未发现广告投放证据时也不会把缺少 Ads/UET 标签当成问题。

扩展会单独识别百度统计和 Clarity，但不会用它们证明 GA4、Google Ads、Microsoft Ads 或真实业务链路正常。它还会区分 hreflang 与移动版 alternate；同源及已授权关联版本会自动核对状态码、最终地址、Canonical、noindex 和页面语言，未授权跨域地址只显示为检测边界，不会自动弹出授权。

用户主动点击“开始测试”后，插件才临时观察页面事件和请求，最长 10 分钟；测试停止、超时、页面卸载或权限失效时恢复页面方法。插件只保存脱敏摘要，不保存请求正文、表单值、Cookie、完整 dataLayer/uetq 或真实业务 ID。Search Console、平台后台、真实搜索引擎抓取和服务器日志无法由浏览器直接确认的内容只列为检测限制；扩展不连接 Google/Bing OAuth，也不读取相关账户。

海外数据核对支持 GA4、广告表现和业务结果 CSV，按“广告点击 → 分析会话 → 分析关键事件 → 平台转化 → 有效业务”展示差异。标签存在、浏览器初始化、请求出现、平台后台收到和后端有效业务被严格分成五层，不会把检测到脚本直接写成追踪正常。

SEM 工作区保留概况、落地页、数据和诊断，支持 Google、Bing、百度广告表现、创意和业务结果。诊断用普通语言解释点击一次平均花多少钱（CPC）、获得平台转化和有效客户的成本（平台 CPA / 有效 CPA）、收入回报（ROAS）和毛利回报，再判断追踪、搜索词、匹配、创意、落地页或真实业务是否造成问题。没有成熟周期、业务边界或毛利数据时只报告事实和风险，不建议调价、扩量或启用自动出价。

优化建议由当前扫描和导入证据实时生成，不保存任务状态，也不要求用户维护负责人、截止时间或处理进度。重新扫描可以验证页面和配置是否改变；技术检查通过不等于收录、排名或业务效果已经提升。

可选 AI 深度解读兼容 OpenAI-compatible `/chat/completions` 请求，优先使用 SSE 流式返回，也兼容非流式 JSON。填写请求地址、模型和 API Key 后，可围绕当前项目连续追问页面、站点、SEO 搜索表现与 SEM 诊断。API Key 和对话只保存在当前 Chrome 用户的扩展本地存储中，浏览器重启后仍保留，并可手动清除。AI 不修改规则、页面 SEO 基础分、预算或账户。

## 单一用途说明

分析用户主动选择的网站搜索增长信号，并在本地提供可解释的 SEO、国际 SEO、追踪链路与 SEM 诊断、优化建议和网页元素定位。

## 权限说明

- activeTab：仅在用户主动使用扩展时访问当前标签页。
- tabs：只识别当前活动标签页的 URL，使扩展从 Chrome 侧边栏入口打开时也能为当前网站申请权限；不读取或保存浏览历史。
- scripting：按需注入审计采集器、网页标注层和用户主动开始测试时的临时追踪观察器。
- storage：保存会话报告、网站记录、规范化 CSV、站点审计、扫描基线、日志聚合、SEM 变更与诊断结果，以及用户配置的 AI 设置、API Key 和对话；优化建议不保存任务状态，所有持久数据均提供删除入口。
- sidePanel：在 Chrome 侧边栏展示审计结果。
- 可选主机权限：只在用户主动持续检测网页、运行当前 origin 站点审计、检查跨域语言页或移动版关联地址、继续跨域转化测试或保存 AI 请求地址时，按对应范围动态申请；海外概况不会自动申请关联版本权限。

## 发布前替换

- 将 `store/privacy-policy.html` 部署为无需登录即可访问的 HTTPS 页面；建议固定地址为 `https://codecc.cc/seo-opt/privacy-policy`。
- 在 Chrome Web Store 开发者后台的“隐私权”页面，将上述完整 URL 填入专门的“隐私权政策”字段。只在商品说明、开发者网站或扩展包中提供政策不算完成。
- 提交前用未登录/无痕窗口确认政策 URL 返回 200、正文可见、不要求 Cookie 同意后才能查看、不跳转到登录页，也不是本地文件、网盘预览或会过期的临时链接。
- 准备 1280×800 或 640×400 的真实功能截图，截图不得包含私密网站、API Key 或用户数据。
- 核对商店后台的数据使用披露与本项目隐私政策一致。
- 版本 0.8.0 使用五张最新截图，覆盖完整优化建议与代码解释、核心 SEO、站点审计、海外建议和 SEM 诊断；上传时按商店后台数量限制选取。

## 隐私权惯例表单建议

即使数据只在本地处理，Chrome 也要求披露。按当前 0.8.0 功能，后台应至少如实声明处理以下类型：

- `网站内容`：页面标题、正文短片段、链接、媒体属性、结构化数据和技术 SEO 信号。
- `网络历史记录/浏览活动`：当前活动页面 URL 和用户主动授权站点审计的同源 URL；同时说明不会持续记录完整浏览历史。
- `身份验证信息`：用户选择保存的第三方 AI API Key。
- `用户生成的内容`：AI 提问、对话以及用户填写的项目配置和广告变更摘要。
- `财务和付款信息`：用户主动导入的广告成本、收入、退款、毛利和转化价值等业务指标。

如果后台没有完全相同的中文标签，应选择含义最接近的类别。不要勾选姓名、邮箱、电话、地址、健康、精确位置或个人通信，因为当前代码不处理这些数据。

数据用途只选择提供扩展核心功能所必需的选项。完成 Limited Use/有限使用认证，并如实确认：不出售数据、不用于个性化广告、不用于与单一用途无关的信用或借贷、不允许人工读取数据（法律、安全或用户明确请求支持等政策允许情形除外）。
