# Chrome Web Store 中文商品文案

## 扩展名称

SEO优化

## 简短说明

自动检查当前网页、站点、海外市场与 Google/Bing 追踪，提供可解释的 SEO/SEM 优化建议、代码示例和验证方法。

## 详细说明

SEO优化是一款面向站长、独立开发者、SEO/SEM 从业者和网站运营者的本地网站检查工具。

点击扩展图标后，插件会在 Chrome 侧边栏自动扫描当前页面。用户不需要先创建项目，也不需要填写关键词、市场或广告信息。扫描完成后，可以直接查看页面现状、已确认问题和完整优化建议。

### 页面 SEO 与技术检查

插件会检查当前页面可以直接取得的 SEO 和技术证据，包括：

- HTTP 状态、最终地址、HTTPS、HSTS、混合资源和正式主机；
- robots.txt、页面 Robots、Canonical、Sitemap 和抓取限制；
- Title、Description、H1-H6、正文、链接、图片 Alt、视频和结构化数据；
- 页面语言、hreflang、移动版关联地址和国际页面关系；
- HTML、CSS、JavaScript 的压缩、缓存和加载方式；
- 原始 HTML 与浏览器渲染内容差异；
- 本次访问可测的 LCP、CLS、FCP 和 TTFB。

证书到期时间、证书链、TLS 等级、真实收录和实际排名等浏览器无法直接确认的内容，会明确显示为检测边界，不会生成虚假结论。

### 问题定位与完整优化建议

“问题”页面只展示有直接证据的失败和警告。每个问题包含结论、发现位置、证据、影响范围和严重程度。支持在原网页中定位对应元素，标注层不会修改网页原有样式或内容。

“优化建议”是插件的核心结果。每项方案会说明：

- 为什么会出现这个问题；
- 为什么值得优化；
- 推荐采用什么策略；
- 应该修改页面、模板、组件、服务器还是 CDN；
- 可使用的代码或配置示例；
- 代码中的变量和关键部分是什么意思；
- 修改后会直接改变什么；
- 可能产生什么搜索或业务效果；
- 哪些结果不能保证；
- 如何验证和回滚。

插件会根据可观察证据识别 WordPress、Shopify、Next.js、Nuxt/Vue、React SPA、静态 HTML、Nginx、Apache 和常见 CDN。证据不足时，插件先说明最终 HTML、响应或事件应该达到的目标，再提供常见技术栈方案，不会武断判断网站框架。

Canonical、hreflang 等示例会使用当前页面的域名和路径。结构化数据只使用页面已经确认的事实，不会虚构价格、评分、库存或作者。

### 站点审计

用户可以主动运行站点审计，默认抽样检查 20 个页面，也可以扩展到 50 或 100 个页面。站点审计用于发现同一模板或一批页面共同存在的问题，例如：

- 重复标题、重复描述和近似重复内容；
- 状态码、跳转、Canonical 和索引规则异常；
- Sitemap、hreflang、内部链接和孤立页候选；
- HTML 压缩、缓存和 nofollow 使用情况。

站点审计遵守 robots.txt，只检查用户授权的网站来源。抽样结果会明确说明检查范围，不会冒充完整全站抓取结果。

### 海外站优化

海外站工作区包含“概况、问题、优化建议、追踪”四个页面。

概况会先判断当前页面是否呈现海外市场建设证据，再分别展示五项能力：

- 搜索访问；
- 本地化内容；
- 海外数据统计；
- 广告追踪；
- 海外转化支持。

插件区分已确认问题、海外能力缺口、条件性建议和检测边界。中文单语言网站不会因为没有 hreflang 被判错；没有广告投放证据时，也不会把缺少 Google Ads 或 Bing UET 标签当成问题。

插件可以识别 GA4、GTM、Google Ads、Bing UET、Clarity 和百度统计，但会严格区分以下证据：

1. 页面存在标签；
2. 浏览器观察到初始化；
3. 浏览器观察到请求；
4. 分析或广告平台后台确认收到；
5. 后端确认产生有效业务。

GTM 容器加载只能证明容器存在，不能证明 GA4 已经发送数据。百度统计或 Clarity 也不能证明 Google Ads、Microsoft Ads 或真实业务链路正常。

### 现场追踪测试与数据核对

普通页面扫描不会持续监听用户操作。只有用户主动开始追踪测试后，插件才临时观察可识别的分析事件、请求和 SPA 路由变化，用于判断咨询、注册、购买或下载是否漏记、重复记录或错误触发。

测试最长 10 分钟，最多保留 200 条内存观察。插件不保存请求正文、表单值、Cookie、完整 dataLayer/uetq 或真实 event_id、lead_id、transaction_id。

用户还可以主动导入 GA4、广告表现和业务结果 CSV，在本地核对“广告点击、分析会话、分析关键事件、平台转化、有效业务”的差异。原始 CSV 不会被长期保存，邮箱、电话、姓名和地址等身份字段禁止映射。

### SEM 诊断

SEM 工作区支持 Google、Bing 和百度广告表现、创意及业务结果数据。插件会用普通语言解释：

- 点击一次平均花多少钱；
- 获得一个平台转化花多少钱；
- 获得一个有效客户花多少钱；
- 广告投入产生多少收入；
- 扣除退款和成本后是否仍有利润。

插件会区分追踪、搜索词、匹配方式、创意、落地页和真实业务问题。缺少成熟周期、有效业务或毛利数据时，只展示事实和风险，不会武断建议调价、扩量或启用自动出价。

### 可选 AI 深度解读

AI 功能默认关闭。用户可以自行配置兼容 OpenAI `/chat/completions` 的 HTTPS 服务地址、模型和 API Key，用于解释当前诊断和优化建议。

API Key 和对话保存在当前 Chrome 用户的扩展本地存储中。插件不会把 API Key、报告或对话自动发送给开发者。只有用户主动发送问题时，相关诊断摘要才会发送给用户选择的 AI 服务。

### 数据与权限边界

- 页面检查、站点审计、CSV 分析和报告默认在本地完成；
- 不持续记录完整浏览历史；
- 不读取 Cookie、密码、支付卡或表单输入值；
- 不连接 Google、Bing 或广告平台 OAuth；
- 不自动修改网站、服务器、CDN、分析标签、广告账户、预算或出价；
- 不申请 debugger 或 webRequest 权限；
- 网站权限只在用户主动运行需要持续访问的功能时按来源申请；
- 页面 SEO 基础分、Schema、标签存在或技术检查结果都不代表收录、排名、流量或收入保证。

## 单一用途说明

分析用户主动选择的网站搜索增长信号，并在本地提供可解释的 SEO、国际 SEO、追踪链路与 SEM 诊断、优化建议和网页元素定位。
