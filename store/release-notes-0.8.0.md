# SEO优化 0.8.0：海外市场判断与完整优化建议

## Breaking Changes

无。升级后会继续读取现有网站记录、站点审计、CSV、AI 对话和追踪历史，不需要重新配置。

## New Features

1. **海外市场建设判断**：海外站概况现在会直接说明当前页面是否呈现海外市场建设证据，并分别展示搜索访问、本地化内容、海外数据统计、广告追踪和海外转化支持五项能力。
2. **完整优化建议**：每项建议新增根因、适用前提、修改位置、技术栈方案、代码解释、变量说明、直接结果、可能效果、验证和回滚，不再只给一段缺少上下文的代码。
3. **海外问题与能力缺口分开**：没有英文站、GA4 或广告标签不会被强行算成技术错误，单语言网站也不会因为没有 hreflang 被误报。
4. **追踪证据分层**：GA4、GTM、Google Ads、Bing UET、Clarity 和百度统计按标签、初始化、请求、平台接收和有效业务五层展示，GTM 容器加载不再冒充 GA4 数据请求。
5. **关联版本检查**：语言页和移动版地址会保留独立的状态码、最终地址、页面语言、Canonical 和 noindex 证据，跨域未授权时只显示检测边界。

## Fixes and Improvements

1. 修复海外概况显示问题数量或确认数量，却没有对应可见内容的情况。
2. 修复同一个追踪问题同时影响多个海外能力区域的重复计数。
3. 修复 Clarity 或百度统计被误解为 Google/Bing 数据统计已经正常的问题。
4. 优化海外站、追踪和数据核对的窄屏排版，长 URL、代码和技术表格只在自身区域滚动。
5. 更新 AI 上下文、Markdown/JSON 导出、隐私政策、商店介绍和五张商店截图，使它们共用同一份海外诊断结论。

## Deprecations

无。0.8.0 不新增权限，也不新增 IndexedDB 数据表。
