# Chrome Web Store 隐私权披露填写说明

版本：0.8.0

本文件用于填写 Chrome Web Store 后台的隐私权和数据使用表单。最终选择应以后台实际提供的字段名称为准，字段名称不完全一致时选择含义最接近的类别。

## 隐私政策地址

计划使用：`https://codecc.cc/seo-opt/privacy-policy`

提交前必须确认该地址在未登录和无痕窗口中返回 200，并直接显示“SEO优化隐私政策”正文。目前该地址返回 New API 首页，尚不符合提交要求。

## 建议披露的数据类型

### 网站内容

选择“是”。扩展会在用户主动扫描时处理页面标题、元数据、正文短片段、链接、媒体属性、结构化数据、页面语言和技术 SEO 信号。

用途：扩展核心功能。

### 浏览历史或网页活动

选择“是”。扩展处理当前活动页面 URL，以及用户主动授权站点审计时检查的同源 URL。扩展不会持续记录完整浏览历史，也不申请 history 权限。

用途：扩展核心功能。

### 用户活动

选择“是”。用户主动开始追踪测试后，扩展会临时观察事件名称、平台、相对时间、路由变化和关键字段是否存在，用于判断转化是否漏记、重复或错误触发。

扩展不保存表单值、Cookie、请求正文、完整 dataLayer/uetq 或真实业务 ID。

用途：扩展核心功能。

### 身份验证信息

选择“是”。用户启用可选 AI 功能时，可以在本地保存第三方 AI 服务的 API Key。

API Key 只发送给用户选择的 AI 服务，不发送给扩展开发者，也不写入导出报告。

用途：扩展核心功能。

### 财务和付款信息

选择“是”。用户可以主动导入广告成本、转化价值、收入、退款和毛利等业务指标，用于本地 SEM 和归因诊断。

扩展不处理支付卡号、银行账户或付款凭证。

用途：扩展核心功能。

### 用户生成内容或个人通信

如果后台提供“用户生成内容”类别，选择“是”，因为扩展可以在本地保存 AI 提问和回复。

如果后台只有“个人通信”类别，应按照后台说明选择最接近的类别，并在说明中写明这些内容是用户与其自行配置的 AI 服务之间的对话，不是短信、邮件或社交通信。

用途：扩展核心功能。

## 建议选择“否”的数据类型

当前版本不处理以下数据：

- 姓名、身份证件和政府签发身份信息；
- 邮箱、电话号码和通讯录；
- 精确位置或粗略位置；
- 健康和医疗信息；
- 支付卡号和银行账户；
- 密码和网页表单输入值；
- Cookie 内容；
- 个人邮件、短信或社交平台消息。

用户导入 CSV 时，姓名、邮箱、电话和地址等身份字段禁止映射。

## 数据使用目的

仅选择“扩展核心功能”或后台含义相同的用途。

不要选择以下用途：

- 个性化广告；
- 广告再营销；
- 信用或借贷；
- 与扩展单一用途无关的市场研究；
- 向数据经纪商提供数据；
- 开发者自己的跨网站跟踪或用户画像。

## Limited Use 声明

应确认以下事实：

- 不出售用户数据；
- 不将用户数据用于个性化广告；
- 不将用户数据用于信用、借贷或保险决策；
- 不将用户数据转移给与扩展核心功能无关的第三方；
- 不允许人工读取用户数据，法律、安全调查或用户明确请求支持等政策允许情形除外；
- 遵守 Chrome Web Store 用户数据政策和 Limited Use 要求。

## 数据保存与删除说明

可填写以下说明：

“扫描报告、站点审计、规范化导入字段、追踪测试和用户设置默认保存在用户本机的 Chrome 扩展存储或 IndexedDB 中。原始 CSV、原始服务器日志、请求正文、表单值和 Cookie 不会持久保存。用户可以删除单项数据、当前网站数据、AI Key、AI 对话或全部本地数据；卸载扩展后，Chrome 会删除扩展本地存储。”

## 第三方 AI 服务说明

可填写以下说明：

“AI 功能默认关闭。只有用户自行配置兼容 OpenAI 的服务地址、模型和 API Key，并主动发送问题后，扩展才会向该服务发送当前页面 URL、诊断摘要、优化建议、最多 4000 字的可见正文短片段和本轮对话。扩展不会发送 Cookie、表单值、完整 DOM、原始 CSV、原始日志、完整 dataLayer/uetq 或真实业务 ID。第三方 AI 服务按照其自身隐私政策处理收到的数据。”
